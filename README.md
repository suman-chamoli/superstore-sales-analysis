# Superstore Sales Analysis (Excel)

## 📌 Project Overview
This project focuses on analyzing a Superstore sales dataset using Microsoft Excel to extract meaningful business insights.

The goal of this project is to understand sales performance, identify profitable areas, and support better decision-making.

---

## 🛠 Tools Used
- Microsoft Excel

---

## 📊 Key Analysis Performed
- Sales analysis across different regions
- Profit analysis by category
- Identification of top-performing products
- Monthly sales trend analysis

---

## 📈 Key Insights
- Certain regions contribute more to overall sales
- Some product categories generate higher profit
- A few products dominate total sales
- Sales show variation over time (monthly trends)

---

## 📁 Files Included
- Superstore dataset (Excel file)

---

## 🚀 Skills Demonstrated
- Data Cleaning
- Data Analysis
- Pivot Tables
- Data Visualization (Charts)
- Business Insights Generation

---

## 🎯 Conclusion
This project demonstrates how Excel can be used as a powerful tool for analyzing business data and generating actionable insights.
